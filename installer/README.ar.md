# توزيع SpectraVision

مثبّت v2 يثبت التطبيق لحساب Windows الحالي ويضيف اختصار **RAM HAX** تلقائيًا على سطح المكتب. يحتفظ بـ`settings.json` و`activation.bin` في مجلد بيانات القناة داخل `%LOCALAPPDATA%` حتى عند تحديث التطبيق. أول تشغيل يتطلب التحقق من الترخيص عبر الإنترنت. يعاد التحقق أثناء التشغيل، وتتوقف الجلسة عند فقد التفويض.

من لوحة الإدارة اضبط مدة الترخيص وحد الأجهزة والباقة. يظهر كود التفعيل مرة واحدة عند الإنشاء. يمكن للمسؤول تمديد الترخيص أو إلغاؤه أو فك ربط جهازه. تنعكس التغييرات في العميل عند التحقق التالي.

## بناء الحزم

```powershell
./installer/build-release.ps1 -Version 2.0.0 -Test
./installer/build-release.ps1 -Version 2.0.0 -Bridge
```

الحزمة الأولى تتصل بـStaging وتستخدم بيانات منتج اختبار مستقل. الخيار `-Test -Local` يستخدم localhost ومسارًا منفصلًا. إصدار الجسر يتصل بواجهة v2 للإنتاج ويتطلب حساب Windows صاحب مفتاح v1. ملفات كل بناء تحت `release/cloud-control/`.

للمتابعة راجع [خطوات الترحيل والتوقيع والرجوع](../docs/migration-runbook.md) و[دليل التشغيل](../docs/operations-runbook.md). تنشر الإصدارات الموقعة عبر GitHub Releases، ويختار المسؤول الإصدار الحالي لكل قناة من لوحة الإدارة بعد نشر ملفاته.

يبقى [مثبّت v1 وواجهة إدارته](https://spectravision-api.ahmed-mabrouk-dev.workers.dev/admin/) في الخدمة أثناء الترحيل. يحتفظ v1 بسلوك التصريح السابق عند انقطاع الاتصال حتى تتم ترقيته.
